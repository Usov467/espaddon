Что умеет

Features

Каждая функция включается отдельно. Выключенная — работает родное окно игры.

Окно группы

  • Клик по имени — участник в цели.
  • Раскладка 1×8 или 2×4, размер 50–200%.
  • Цвет полосы HP по здоровью или один свой.
  • Бафы и дебафы участников. Можно оставить только выбранные бафы — видно, кому чего не хватает.

Радар

  • Фильтр точек: группа, метки, каждая раса, NPC, монстры, анимусы, башни, шахтёры и т. д. Только скрывает — новых точек не добавляет.
  • Размер 100–300%, прозрачность, дальность 1–5 (колесо мыши над радаром).
  • Кольцо потери аггро: дальше него мобы бросают погоню.

Панель цели

  • Точный процент HP любой цели.
  • Значки свойств моба, бафы и дебафы цели.

Персонажи

  • Подсветка моделей своим цветом: цель, группа, метки, лидер гильдии.
  • Строка гильдии над головой: значок, название и рейтинг отключаются отдельно для своей гильдии, своей и чужой расы.
  • Скрытие имён суммонов.

TeamSpeak

Возможность собрать группу по каналу TeamSpeak: правый клик по кнопке Espaddon — и всем, кто сидит с вами в канале, уходит приглашение в группу. Работает с TeamSpeak 3 и 5–6; если ник в TS отличается от игрового, их можно сопоставить в настройках.

Проверка готовности

ПКМ по кнопке → «Проверка готовности». Запрос в чат группы; ответом считается любое сообщение участника. Итог в чат — когда ответили все или через 60 с.

Продажа мусора

Кнопка у магазина NPC кладёт мусор из сумки в окно продажи; продаёте сами.

Производительность

  • Счётчик FPS.
  • Реже анимировать дальних персонажей: до +12% FPS в толпе.
  • Extra FPS: отрисовка через DXVK (Vulkan), +20–30% FPS в толпе.

Исправления клиента

  • Без тряски камеры в бою.
  • Снятие бафов, залипших после быстрого воскрешения.

Раскладка

Пока открыты настройки, окна двигаются мышью по сетке RFMods (10 px). Shift — без привязки, ПКМ — вернуть на место.

Each feature can be turned off separately — the game's own window takes its place.

Party window

  • Click a name to target the member.
  • 1×8 or 2×4 layout, size 50–200%.
  • HP bar colored by health or a single color.
  • Members' buffs and debuffs. Show only selected buffs to see who is missing what.

Radar

  • Dot filter: party, marks, each race, NPC, monsters, animus, towers, miners, etc. Hides only — adds no new dots.
  • Size 100–300%, transparency, range 1–5 (mouse wheel over the radar).
  • Aggro-loss ring: beyond it mobs stop chasing.

Target frame

  • Exact HP percentage of any target.
  • Monster property icons, target buffs and debuffs.

Characters

  • Model highlighting in your colors: target, party, marks, guild leader.
  • Guild line above heads: emblem, name and rank toggle separately for own guild, own race and other race.
  • Hide summon names.

TeamSpeak

Gather a party from your TeamSpeak channel: right click the Espaddon button and everyone in your channel gets a party invite. Works with TeamSpeak 3 and 5–6; if a TS name differs from the game name, map them in the settings.

Ready check

Right click the button → "Ready check". A request goes to party chat; any message from a member counts as an answer. Result goes to chat when all answered or after 60 s.

Sell junk

A button at the NPC shop puts junk from the bag into the sell window; you sell yourself.

Performance

  • FPS counter.
  • Animate distant characters less often: up to +12% FPS in crowds.
  • Extra FPS: rendering through DXVK (Vulkan), +20–30% FPS in crowds.

Client fixes

  • No camera shake in combat.
  • Removes buffs stuck after a quick revive.

Layout

While settings are open, windows drag on the RFMods grid (10 px). Shift — no snapping, right click — back to default.

Guides

Установка

Installing

  1. Распакуйте папку Espaddon в папку игры, рядом с RF_Online_4gb.bin.
  2. При закрытых игре и лаунчере запустите Espaddon\install.bat.

Чужой d3d9.dll (ReShade и т. п.) сохраняется как d3d9.dll.esp-backup. Кнопка Espaddon появится в ряду кнопок RFMods.

  1. Unpack the Espaddon folder into the game folder, next to RF_Online_4gb.bin.
  2. With the game and launcher closed, run Espaddon\install.bat.

Another d3d9.dll (ReShade etc.) is kept as d3d9.dll.esp-backup. The Espaddon button appears in the RFMods button row.

Обновление

Updating

Новая версия — оранжевая точка на кнопке. При закрытых игре и лаунчере запустите Espaddon\update.bat: скачает тот же вариант, проверит SHA-256, поставит. Настройки сохраняются.

С версии 0.16.0 и старше — один раз через «Установку»: update.bat там нет.

A new version shows as an orange dot on the button. With the game and launcher closed, run Espaddon\update.bat: it downloads the same variant, checks SHA-256 and installs. Settings stay.

From 0.16.0 or older — once via "Installing": there is no update.bat yet.

Удаление

Uninstalling

При закрытой игре — Espaddon\uninstall.bat. Вернёт чужой d3d9.dll, если он был. Папку Espaddon с настройками удалите вручную.

With the game closed — Espaddon\uninstall.bat. Restores another d3d9.dll if there was one. Delete the Espaddon folder with settings by hand.

Проблемы

Problems

Кнопка есть, аддон не работает

Клик по кнопке покажет причину. Обычно — персонаж не из ESPADA: гильдия проверяется при первом входе в мир, для смены нужен перезапуск игры.

После обновления клиента вернулись родные окна

Аддон не знает новый клиент и отключается сам. Ждите новую версию.

Залипли бафы

ПКМ по кнопке → «Убрать залипшие бафы».

Другое

Пришлите Tooky файл Espaddon\logs\espaddon.log и опишите, что случилось.

Button is there, addon does nothing

Click the button for the reason. Usually the character is not in ESPADA: the guild is checked at the first world entry, switching needs a game restart.

Native windows are back after a client update

The addon does not know the new client and turns itself off. Wait for a new version.

Stuck buffs

Right click the button → "Remove stuck buffs".

Something else

Send Espaddon\logs\espaddon.log to Tooky and describe what happened.

Вопросы

FAQ

Это против правил?Is it against the rules?

Только интерфейс: пакеты и механику не трогает, скрытого не показывает.

Interface only: no packets or mechanics, shows nothing hidden.

RFMods и ReShade?RFMods and ReShade?

RFMods — совместим. ReShade — тоже d3d9.dll, вместе не работают; установщик сохраняет его копию.

RFMods — compatible. ReShade is also d3d9.dll, they don't run together; the installer keeps a backup.

Обычная или Extra FPS?Standard or Extra FPS?

Функции одинаковые. Extra FPS быстрее в толпе, но зависит от видеокарты.

Same features. Extra FPS is faster in crowds but depends on the GPU.

Аддон ходит в интернет?Does it go online?

Раз за запуск спрашивает у GitHub номер последней версии. Выключить: check=0 в [update] файла Espaddon\espaddon.ini.

Once per launch it asks GitHub for the latest version number. Off: check=0 in [update] of Espaddon\espaddon.ini.
